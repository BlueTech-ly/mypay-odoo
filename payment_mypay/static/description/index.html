MyPay

Accept Libyan payments in Odoo 18 through MyPay hosted checkout.

Features

  • Hosted redirect checkout (LYD)
  • Gateway aliases: Moamalat, Masrafi Pay, Yasr Pay, Sahary Pay, Edfali, SADAD, Mobicash
  • Staff pay-on-behalf from customer invoices
  • Payment Status enquiry + optional signed webhooks + cron recovery

الميزات

  • دفع مستضاف عبر MyPay (دينار ليبي)
  • بوابات محلية عبر gateway aliases
  • دفع الموظف نيابة عن العميل من الفاتورة
  • تأكيد عبر Payment Status وWebhook اختياري ومهمة مجدولة

Setup: Install MyPay, open Payment Providers → MyPay, enter Client ID / Secret ID, set Test or Enabled.

Docs: https://mypay.ly
