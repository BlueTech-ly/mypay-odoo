MyPay

Accept Libyan Dinar (LYD) payments in Odoo 18 through MyPay hosted checkout — with local bank and wallet gateways, staff-assisted payment, and reliable confirmation.

Features

  • Hosted checkout — redirect customers to MyPay’s secure payment page.
  • Local gateways — pre-select a gateway via MyPay aliases (no need to pick again on MyPay when Auto-Submit is used).
  • Staff pay on behalf — from a posted customer invoice, open Pay via MyPay, choose a gateway, enter a Libyan mobile, and complete payment with the customer present.
  • Reliable confirmation — Payment Status enquiry on return, optional signed webhooks, and a scheduled job for closed browsers / late success.
  • Point of Sale — companion module pos_mypay for online POS payment (QR / hosted link).

How payment is confirmed

  • Payment Status — Odoo calls MyPay after return/cancel (no public HTTPS required).
  • Cron — re-checks pending (and recently canceled) transactions if the shopper closed the browser.
  • Webhook — optional faster confirmation when a public HTTPS URL is available.

Setup

  1. Install MyPay from Apps.
  2. Open Invoicing / Accounting → Configuration → Payment Providers → MyPay.
  3. Enter Client ID and Secret ID from the MyPay merchant dashboard.
  4. Set the provider to Test (sandbox) or Enabled (production).
  5. (Optional) Configure webhook secret + public HTTPS URL for inbound webhooks.
  6. For staff-assisted payments: open a posted customer invoice → Pay via MyPay → choose gateway + Libyan phone (09xxxxxxxx).

Requirements & limits

  • Odoo 18.0
  • Currency: LYD only
  • No refund API — handle refunds manually in Odoo and the MyPay dashboard
  • No card tokenization / saved payment methods

الميزات

  • دفع مستضاف — توجيه العميل إلى صفحة MyPay الآمنة.
  • بوابات محلية — اختيار بوابة مسبقاً عبر gateway aliases (مع الهاتف الليبي يمكن تجاوز صفحة كل البوابات).
  • دفع الموظف نيابة عن العميل — من فاتورة مرحّلة: الدفع عبر MyPay → اختيار البوابة + رقم جوال ليبي → إتمام الدفع مع حضور العميل.
  • تأكيد موثوق — استعلام Payment Status، وWebhook اختياري، ومهمة مجدولة عند إغلاق المتصفح.
  • نقطة البيع — وحدة مرافقة pos_mypay للدفع أونلاين من الـ POS.

التثبيت

  1. ثبّت MyPay من التطبيقات.
  2. افتح الفوترة / المحاسبة ← الإعدادات ← مزودو الدفع ← MyPay.
  3. أدخل معرف العميل والمفتاح السري.
  4. اضبط الحالة على اختبار أو مفعّل.
  5. (اختياري) اضبط الويب هوك عند توفر HTTPS عام.
  6. لدفع الموظف: فاتورة مرحّلة → الدفع عبر MyPay → بوابة + هاتف 09xxxxxxxx.
