POS MyPay

Accept MyPay payments from the Point of Sale using Odoo’s online payment flow (QR code / hosted checkout link).

Features

  • Works with the main MyPay provider (payment_mypay).
  • Uses Odoo pos_online_payment QR / link payment.
  • Auto-installs when Point of Sale is installed.

Setup

  1. Install and configure MyPay (Test or Enabled) with API credentials.
  2. Open Point of Sale → Configuration → Payment Methods → MyPay and allow the MyPay provider.
  3. Add MyPay to your shop’s payment methods.
  4. Close any open session, open a new one, and choose MyPay at payment.

Requirement

Company currency must be LYD (MyPay supports Libyan Dinar only).

الميزات

  • يعمل مع مزوّد MyPay الرئيسي.
  • دفع عبر QR / رابط مستضاف من نقطة البيع.
  • تثبيت تلقائي مع وحدة نقطة البيع.

التثبيت

  1. ثبّت واضبط MyPay.
  2. أضف طريقة دفع MyPay للمتجر وافتح جلسة جديدة.
  3. العملة يجب أن تكون LYD.
